# Vite SPA Boilerplate

A modern boilerplate for building Single Page Applications (SPA) with Vite.

## Overview

This boilerplate provides a solid foundation for developing fast and efficient single-page applications using Vite's lightning-fast build tooling and hot module replacement (HMR).

## Features

- **Fast Development**: Leverages Vite's native ES modules for instant server start and lightning-fast HMR
- **Optimized Build**: Production builds are optimized with Rollup for minimal bundle sizes
- **Modern Tooling**: Built with modern JavaScript standards and best practices

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
